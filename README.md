# News Article Classification Using Machine Learning

## 1. Project Overview

This project focuses on classifying news articles into different categories using machine learning algorithms. The aim is to compare four classification algorithms and identify which performs best for news article classification.

## 2. Dataset Description

This project uses the **20 Newsgroups dataset** with four selected categories:

| Category          | Dataset Label        |
| ----------------- | -------------------- |
| Sports            | `rec.sport.baseball` |
| Science           | `sci.space`          |
| Politics          | `talk.politics.misc` |
| Computer Graphics | `comp.graphics`      |

The dataset contains news articles belonging to these four different topics.

## 3. Objectives

* To understand text classification using machine learning.
* To preprocess news article text.
* To convert text into numerical features using TF-IDF.
* To implement four classification algorithms.
* To evaluate and compare model performance.
* To identify the best-performing classifier.

## 4. Algorithms Implemented

The following four machine learning algorithms are used:

1. Decision Tree
2. K-Nearest Neighbors (KNN)
3. Support Vector Machine (SVM)
4. Naïve Bayes

## 5. Text Preprocessing

The following text processing techniques are used:

* Lowercase conversion
* Tokenization
* Stop-word removal
* TF-IDF feature extraction
* L2 normalization

## 6. Technologies Used

* Python
* Google Colab
* Scikit-learn
* Pandas
* NumPy
* Matplotlib

## 7. Evaluation Metrics

The classification models are evaluated using:

* Accuracy
* Precision
* Recall
* F1-score
* Confusion Matrix

## 8. What-if Experiment

A what-if experiment is performed using the K-Nearest Neighbors algorithm by changing the value of K (number of neighbors) to study its effect on classification performance.

## 9. Project Files

This repository contains:

* Python Jupyter Notebook
* Dataset CSV file
* Model comparison results
* KNN what-if experiment results
* Algorithm comparison graph
* Confusion matrix
* KNN experiment graph
* Project report (PDF)

## 10. Conclusion

This project compares four machine learning algorithms for news article classification. Their performance is evaluated using standard classification metrics to understand their strengths and weaknesses and identify the most suitable model.
